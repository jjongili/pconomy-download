# 프코노미 스마트툴

[최신 배포판 다운로드](https://github.com/jjongili/pconomy-download/releases/latest)에서 Windows 실행파일을 받으세요.

배포 파일은 **`pconomy-smarttool-v*.exe` 하나**입니다. 여러 스마트스토어의 초기 설정(계정·공지·쿠폰·노출요소·반품 문의)과 이후 운영 작업을 한 프로그램에서 처리합니다.

사용하려면 활성화 코드가 필요합니다. 기존 운영판 코드(`PCO`)도 그대로 사용할 수 있습니다. 코드는 배포자에게 개별적으로 받으세요.

업데이트는 자동 설치되지 않습니다. 새 버전이 공지되면 위 페이지에서 새 EXE를 받아 실행하세요. 저장된 계정·로그인 정보는 EXE 밖의 `%APPDATA%\PkonomyClient`에 보관되어 버전을 바꿔도 그대로 읽습니다.

이 저장소에는 배포 안내와 실행파일만 공개합니다. 프로그램 소스와 계정 정보는 포함하지 않습니다.
